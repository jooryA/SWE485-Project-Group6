# Model Visualization Plots

This section presents the evaluation plots for **Baseline Logistic Regression, Tuned Logistic Regression, and Tuned Random Forest**.

## Baseline Logistic Regression

### Confusion Matrix

**File:** `lr_baseline_confusion_matrix.png`

This plot shows the confusion matrix of the Baseline Logistic Regression model on the test dataset. It illustrates the correct and incorrect predictions for retained and churned customers.

### ROC Curve

**File:** `lr_baseline_roc_curve.png`

This plot shows the ROC curve of the Baseline Logistic Regression model, illustrating its ability to distinguish between churned and retained customers across different classification thresholds.
